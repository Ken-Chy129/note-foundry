# Single owner with space-level public reading

The first version has one Knowledge Owner and no collaborative users, while anonymous readers and search engines may access published Learning Notes in public Knowledge Spaces through the deployed website. Visibility is controlled at the Knowledge Space level and inherited by Learning Notes; moving a private note into a public space requires one confirmation that simultaneously moves and publishes it, while all other moves immediately follow the target space. Learning Sources, the Source Inbox, Note Drafts, Note Revisions, and management surfaces remain private and non-indexable. Public notes may expose citation metadata and original source URLs without exposing captured text or files, avoiding a general-purpose permissions system while still supporting public sharing.
